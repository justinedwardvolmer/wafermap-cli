# Security

This package holds a private key that can move real money. Please report anything that could leak the key, sign a payment above the caps, or pay an address the user did not approve.

Report privately to hello@wafermap.com, or through a private GitHub security advisory on this repository. Please do not open a public issue for a vulnerability.

Good practice for users: keep only a small balance on an agent wallet, keep the default caps (or lower them), and back up the key with `wafermap export-key`.
